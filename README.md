# funfunding_program
# python manage.py runserver 실행 가능

1. 해당 컴퓨터에 필요한 개발 환경이 준비되어 있어야 합니다:
Python 설치
Django 및 기타 의존성 패키지 설치 (pip install -r requirements.txt)

2. 코드 실행 및 개발 서버 시작:
명령어 $ python manage.py runserver를 사용하면 기본적으로 http://127.0.0.1:8000에서 프로그램이 실행됩니다.
이 경우, 해당 컴퓨터에서만 접근할 수 있습니다.

3. pip install -r requirements.txt
명령어를 통해서 requirements.txt에 기록된 패키지를 모두 설치해야 합니다.

4. python manage.py runserver
명령어로 서버를 run시키고 http://127.0.0.1:8000/ 링크를 얻을 수 있습니다. 전체를 ctrl+s로 제대로 저장되었는지 확인 후에 실행하는 것이
성공 확률이 높았습니다. 

5. 기본적으로 모든 개발은 가상환경 venv 활성화 후에 진행했습니다.
venv 활성화 후에 진행해야 다른 패키지 충돌이 발생하지 않으므로 설치 및 실행을 권장합니다.
